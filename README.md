A haiku about debugging, written for the make.fun bounty
"Seventeen Syllables of Debugging". `main.py` writes the haiku to
`/output/entry.txt`.

> The breakpoint waits, still
> one line fails, then fails again
> it was a comma

Three lines, 5-7-5 syllables: a breakpoint holding its breath while one
line keeps failing — until the last line turns the whole hunt into a
single missing comma.
